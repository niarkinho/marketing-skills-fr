# Référence des types d'outils gratuits

Guide détaillé de chaque type d'outil marketing que vous pouvez construire.

## Sommaire
- Calculateurs
- Générateurs
- Analyseurs/Auditeurs
- Testeurs/Validateurs
- Bibliothèques/Ressources
- Éducatif interactif
- Exemples de concepts d'outils par secteur (produit SaaS, agence/services, e-commerce, outils développeur, finance)

## Calculateurs

**Idéal pour** : Décisions impliquant des chiffres, comparaisons, estimations

**Exemples** :
- Calculateur de ROI
- Calculateur d'économies
- Outil de comparaison de coûts
- Calculateur de salaire
- Estimateur d'impôts
- Estimateur de prix
- Calculateur d'intérêts composés
- Calculateur de seuil de rentabilité

**Pourquoi ils marchent** :
- Sortie personnalisée
- Forte valeur perçue
- Résultats partageables
- Problème clair → solution

**Conseils de mise en œuvre** :
- Gardez les entrées simples
- Montrez les calculs en toute transparence
- Rendez les résultats partageables
- Ajoutez un branding « powered by »

---

## Générateurs

**Idéal pour** : Créer quelque chose d'utile rapidement

**Exemples** :
- Générateur de politiques (confidentialité, CGU)
- Générateur de templates
- Générateur de noms/taglines
- Générateur de lignes d'objet d'email
- Constructeur de CV
- Générateur de palettes de couleurs
- Créateur de logo
- Générateur de contrats

**Pourquoi ils marchent** :
- Sortie tangible
- Fait gagner du temps
- Facilement partagé
- Usage répété

**Conseils de mise en œuvre** :
- La sortie doit être immédiatement utilisable
- Permettez la personnalisation
- Offrez des options de téléchargement/export
- Incluez un gating par email pour les sorties premium

---

## Analyseurs/Auditeurs

**Idéal pour** : Évaluer un travail ou des assets existants

**Exemples** :
- Notation de site web
- Analyseur SEO
- Testeur de ligne d'objet d'email
- Analyseur de titres
- Vérificateur de sécurité
- Auditeur de performance
- Vérificateur d'accessibilité
- Analyseur de qualité de code

**Pourquoi ils marchent** :
- Pilotés par la curiosité
- Insights personnalisés
- Crée une prise de conscience des problèmes
- Mène naturellement à la solution

**Conseils de mise en œuvre** :
- Score ou note pour la gamification
- Benchmark face aux moyennes
- Fournissez des recommandations actionnables
- Faites un suivi avec des offres d'amélioration

---

## Testeurs/Validateurs

**Idéal pour** : Vérifier si quelque chose fonctionne

**Exemples** :
- Preview de balises meta
- Test de rendu d'email
- Test mobile-friendly
- Test de vitesse
- Vérificateur DNS
- Vérificateur de certificat SSL
- Vérificateur de redirections
- Détecteur de liens cassés

**Pourquoi ils marchent** :
- Utilité immédiate
- Méritent d'être mis en favori
- Usage répété
- Nécessité professionnelle

**Conseils de mise en œuvre** :
- Des résultats rapides sont essentiels
- Montrez clairement le succès/échec
- Fournissez des instructions de correction
- Intégrez avec votre produit là où c'est pertinent

---

## Bibliothèques/Ressources

**Idéal pour** : Matériel de référence

**Exemples** :
- Bibliothèque d'icônes
- Bibliothèque de templates
- Bibliothèque de snippets de code
- Galerie d'exemples
- Annuaire de secteur
- Liste de ressources
- Collection de swipe files
- Outil d'association de polices

**Pourquoi ils marchent** :
- Forte valeur SEO
- Trafic continu
- Établit l'autorité
- Asset linkable

**Conseils de mise en œuvre** :
- Rendez-le cherchable/filtrable
- Permettez la copie/le téléchargement faciles
- Mettez à jour régulièrement
- Acceptez les soumissions de la communauté

---

## Éducatif interactif

**Idéal pour** : Apprendre/comprendre

**Exemples** :
- Tutoriels interactifs
- Playgrounds de code
- Explicatifs visuels
- Quiz/évaluations
- Simulateurs
- Outils de comparaison
- Arbres de décision
- Configurateurs

**Pourquoi ils marchent** :
- Engagent en profondeur
- Démontrent l'expertise
- Partageables
- Créent du souvenir

**Conseils de mise en œuvre** :
- Rendez-le concret et pratique
- Montrez un feedback immédiat
- Menez vers des ressources plus approfondies
- Captez les utilisateurs engagés

---
