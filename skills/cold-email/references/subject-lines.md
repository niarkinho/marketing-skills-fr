# Optimisation des objets

L'objet détermine si l'email est lu. Les données sont contre-intuitives : **les objets courts, banals et qui ont l'air internes gagnent nettement.**

## Longueur : 2–4 mots

- Les objets de 2 mots obtiennent **60 % d'ouvertures en plus** que ceux de 5 mots (Lavender).
- Passer de 2 à 4 mots réduit les réponses de **17,5 %**.
- 2–4 mots donnent **46 % de taux d'ouverture** contre 34 % pour 10 mots (Belkins, 5,5M d'emails).
- Le mobile tronque à 30–35 caractères — la concision est une nécessité pratique.

## Principe du camouflage interne

Les objets qui ont l'air de venir d'un collègue, pas d'un fournisseur, doublent les taux d'ouverture (Gong). Les acheteurs catégorisent mentalement avant d'ouvrir — si ça ressemble à du commercial, c'est filtré.

**Exemples performants :** « taux de réponse » · « retards d'essai » · « hiring ops » · « turnover » · « prévision T2 » · « nouveaux patients » · « problème de perso » · « deuxième page »

## Casse : les minuscules gagnent

Le tout-en-minuscules a les meilleurs taux d'ouverture (Gong, 85M+ d'emails). Les minuscules font plus personnel/interne. Pour le cold outreach spécifiquement, les minuscules battent la capitalisation de titre.

## Personnalisation : le contexte plutôt que le nom

Les objets personnalisés boostent les ouvertures de **26–50 %**, mais le type compte :

- **Le prénom dans l'objet → 12 % de réponses en moins.** Signale l'automatisation.
- **La personnalisation contextuelle marche :** points de douleur, concurrents, trigger events, enjeux sectoriels.
- Utiliser {{painPoint}}, {{competitor}}, {{commonGround}} — pas {{firstName}}.

## Questions : seulement si très spécifiques

Les données se contredisent : Belkins dit que les questions performent bien (46 % de taux d'ouverture). Lavender dit que les questions baissent les ouvertures de **56 %**. Compromis : **les questions précises sur la douleur marchent** (« Besoin d'aide sur {{challenge}} ? »), **les questions génériques échouent** (« Petite question ? » / « Vous avez 15 minutes ? »). Par défaut, des affirmations.

## Ce qu'il faut éviter

| Anti-pattern                                   | Impact                      |
| ---------------------------------------------- | --------------------------- |
| Langage commercial (« augmentez », « boostez », « ROI ») | -17,9 % d'ouvertures |
| Mots d'urgence (« ASAP », « urgent »)          | Sous 36 % d'ouvertures      |
| Ponctuation excessive (« !!! » ou « ?? »)      | -36 % d'ouvertures          |
| Chiffres et pourcentages                       | -46 % d'ouvertures          |
| Emojis                                         | Nuisent au professionnalisme B2B |
| Pitcher le produit dans l'objet                | -57 % de réponses           |
| Objet vide / absent                            | +30 % d'ouvertures mais -12 % de réponses |
| Déclencheurs de spam (« gratuit », « garantie », « agissez maintenant ») | Risque de délivrabilité |

## Objets pour C-Suite

Les dirigeants reçoivent 300–400 emails par jour, décident en quelques secondes. Ils répondent **23 % plus souvent** que le non-C-suite quand l'email passe leur filtre (6,4 % de taux de réponse).

Ce qui marche : ultra-concis, humain, sobre. « {{companyInitiative}} » · « merci » · « une mise à jour » · « une question » · référence à un projet précis ou un trigger event.

Tout ce qui sonne « commercial » est immédiatement rejeté.
