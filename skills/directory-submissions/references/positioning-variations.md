# Bibliothèque de variations de positionnement

Les audiences d'annuaires réagissent à des cadrages différents. Ne jamais copier-coller la même description partout — les moteurs IA pénalisent le contenu dupliqué, et chaque type d'annuaire récompense une ouverture différente.

Utilisez cette bibliothèque pour générer des variantes par tier. Remplacez `[produit]`, `[catégorie]`, `[concurrents]`, `[cas-usage]` et `[audience]` par les vraies valeurs.

---

## Cadre : la phrase d'attaque varie selon le tier

| Tier | Pattern de phrase d'attaque | Pourquoi |
|---|---|---|
| Startup / lancement | « [Produit] est le moyen le plus simple de [résultat] pour [audience]. » | Les fondateurs scannent pour la clarté du résultat. |
| Annuaire SaaS | « [Produit] est l'alternative [différenciateur] à [concurrents]. » | Capte l'intention de recherche « [concurrent] alternative ». |
| Annuaire IA | « [Produit] utilise [capacité IA] pour [résultat]. » | Les audiences TAAFT/Futurepedia veulent explicitement de l'IA. |
| Agent / MCP | « [Produit] est un(e) [catégorie] MCP-native / agent-native. » | Niche mais à forte intention. Élimine les concurrents. |
| No-code | « [Produit] vous permet de construire [output] sans code. » | L'audience valorise la vitesse, pas la profondeur technique. |
| Outil dev | « [Produit] est un(e) [catégorie technique] avec [différenciateur]. » | Les devs veulent de la substance d'emblée. |
| Avis B2B | « [Produit] aide [audience] à [résultat business mesurable]. » | Les évaluateurs veulent un langage de ROI. |

>
> Essayez-le gratuitement sur [url]. Sans carte bancaire, sans configuration.

**Tags :** [catégorie produit], [type d'audience], [cas-usage 1], [cas-usage 2], [différenciateur], [tech]

## Référence rapide À faire / À éviter

**À FAIRE :**
- Varier la phrase d'ouverture selon les tiers
- Utiliser de vrais chiffres et des différenciateurs précis
- Adapter le ton à l'audience (technique pour les devs, business pour G2, enthousiaste pour PH)
- Inclure un angle fondateur/origine dans les annuaires de startups
- Attaquer par l'angle AI-first dans les annuaires IA

**À ÉVITER :**
- Copier-coller la même description de 150 mots partout
- Utiliser des affirmations vagues (« ultra rapide », « révolutionnaire »)
- Mentionner chaque fonctionnalité — en choisir 3 à 5 par tier et les faire tourner
- Mentir sur les fonctionnalités des concurrents (les moteurs IA croisent les références et déclassent)
- Sauter la liste de tags — c'est ainsi que les modérateurs vous orientent vers la bonne catégorie
