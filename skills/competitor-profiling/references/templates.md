# Templates de profil

Templates prêts à l'emploi pour les sections de profil concurrent et le document de synthèse.

## Sommaire
- Template scan rapide
- Tableau comparatif de synthèse
- Carte de positionnement
- SWOT concurrentiel
- Changelog de mise à jour de profil

---

## Template scan rapide

Profil abrégé pour quand la vitesse compte plus que la profondeur.

```markdown
# [Nom du concurrent] — Profil rapide

**URL** : [site web]
**Généré** : [date]

## En un coup d'œil

| Métrique | Valeur |
|--------|-------|
| Tagline | [depuis la page d'accueil] |
| Audience cible | [déduite de la copy] |
| Tarif à partir de | [palier payant le plus bas] |
| Offre gratuite/essai | [oui/non + détails] |
| Domain rank | [depuis DataForSEO] |
| Trafic organique est. | [mensuel] |
| Mots-clés organiques (top 10) | [nombre] |
| Domaines référents | [nombre] |

## Positionnement

**Accroche** : « [accroche exacte de la page d'accueil] »
**Sous-accroche** : « [sous-accroche exacte] »
**Angle de positionnement** : [synthèse en 1-2 phrases de leur positionnement]

## Synthèse des tarifs

| Palier | Prix | Inclusions notables |
|------|-------|-------------------|
| [palier] | [prix] | [éléments clés] |
| [palier] | [prix] | [éléments clés] |

## Enseignement clé

[2-3 phrases : ce qui rend ce concurrent notable, où il est fort, où il est faible]
```

## Carte de positionnement

Représentation visuelle de la position des concurrents selon deux dimensions clés. Choisissez les deux axes les plus pertinents pour votre marché.

### Paires d'axes courantes

| Type de marché | Axe X | Axe Y |
|-------------|--------|--------|
| Outils SaaS | Simple → Complexe | Bon marché → Cher |
| Outils développeur | Low-code → Code-first | Individuel → Équipe |
| Plateformes B2B | Orienté PME → Orienté grand compte | Solution ponctuelle → Plateforme |
| Outils de contenu | Piloté par template → Sur mesure | Self-serve → Géré |

### Format

```markdown
## Carte de positionnement

**Axes** : [label axe X] vs. [label axe Y]

                    [label axe Y haut]
                           │
                           │
          [Concurrent A]   │    [Concurrent B]
                           │
    ───────────────────────┼───────────────────────
    [axe X bas]            │            [axe X haut]
                           │
          [Votre produit]  │    [Concurrent C]
                           │
                    [label axe Y bas]

### Interprétation
- [1-2 phrases sur ce que révèle la carte]
- [où se trouve l'espace libre / l'opportunité]
```

## SWOT concurrentiel

SWOT par concurrent, relatif à votre produit.

```markdown
## SWOT : [Concurrent] vs. [Votre produit]

### Forces (les leurs vs. les nôtres)
- [Là où ils nous surpassent réellement — soyez honnête]

### Faiblesses (les leurs vs. les nôtres)
- [Là où ils sont en retrait par rapport à nous — avec preuve]

### Opportunités (pour nous)
- [Lacunes de leur offre que nous pouvons exploiter]
- [Segments qu'ils ignorent]
- [Angles de messaging qu'ils manquent]

### Menaces (de leur part)
- [Domaines où ils s'améliorent vite]
- [Fonctionnalités qu'ils construisent et qui recoupent les nôtres]
- [Mouvements de marché susceptibles de faire bouger la perception]
```

## Changelog de mise à jour de profil

À ajouter en bas de tout profil lors de sa mise à jour.

```markdown
---

## Change Log

| Date | Ce qui a changé | Source |
|------|-------------|--------|
| [date] | Tarif passé de X € à Y € | Re-scrape de la page de tarifs |
| [date] | Lancement de [fonctionnalité] | Scrape du changelog |
| [date] | Domain rank passé de X à Y | Re-récupération DataForSEO |
| [date] | Ajout de [intégration] | Re-scrape de la page intégrations |
```
