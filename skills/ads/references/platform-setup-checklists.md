# Checklists de configuration des plateformes

Checklists de configuration complètes pour les grandes régies publicitaires.

## Sommaire
- Configuration Google Ads (Fondations du compte, Tracking de conversion, Intégration analytics, Configuration des audiences, Préparation des campagnes, Extensions d'annonces, Protection de marque)
- Configuration Meta Ads (Fondations du Business Manager, Pixel & tracking, Domaine & événements agrégés, Configuration des audiences, Catalogue, Assets créatifs, Conformité)
- Configuration LinkedIn Ads (Fondations du Campaign Manager, Insight Tag & tracking, Configuration des audiences, Lead Gen Forms, Document Ads, Assets créatifs, Considérations budgétaires)
- Configuration Twitter/X Ads (Fondations du compte, Tracking, Configuration des audiences, Créa)
- Configuration TikTok Ads (Fondations du compte, Pixel & tracking, Configuration des audiences, Créa)
- Checklist universelle pré-lancement

## Configuration Google Ads

### Fondations du compte

- [ ] Compte Google Ads créé et vérifié
- [ ] Informations de facturation ajoutées
- [ ] Fuseau horaire et devise réglés correctement
- [ ] Accès au compte accordé aux membres de l'équipe

### Tracking de conversion

- [ ] Google tag installé sur toutes les pages
- [ ] Actions de conversion créées (achat, lead, inscription)
- [ ] Valeurs de conversion attribuées (si applicable)
- [ ] Enhanced conversions activées
- [ ] Conversions de test se déclenchant correctement
- [ ] Import des conversions depuis GA4 (optionnel)

### Intégration analytics

- [ ] Google Analytics 4 lié
- [ ] Auto-tagging activé
- [ ] Audiences GA4 disponibles dans Google Ads
- [ ] Tracking cross-domain configuré (si plusieurs domaines)

### Configuration des audiences

- [ ] Tag de remarketing vérifié
- [ ] Audiences de visiteurs du site web créées :
  - Tous les visiteurs (180 jours)
  - Visiteurs de pages clés (prix, démo, fonctionnalités)
  - Convertis (pour exclusion)
- [ ] Listes customer match uploadées
- [ ] Audiences similaires activées

### Préparation des campagnes

- [ ] Listes de mots-clés négatifs créées :
  - Négatifs universels (gratuit, emploi, carrières, avis, plaintes)
  - Négatifs concurrents (si nécessaire)
  - Termes sectoriels non pertinents
- [ ] Ciblage géographique défini (inclure/exclure)
- [ ] Ciblage linguistique défini
- [ ] Planning des annonces configuré (si B2B, heures ouvrées)
- [ ] Ajustements d'enchères par appareil envisagés

### Extensions d'annonces

- [ ] Sitelinks (4-6 pages pertinentes)
- [ ] Callouts (bénéfices clés, offres)
- [ ] Snippets structurés (fonctionnalités, types, services)
- [ ] Extension d'appel (si les leads téléphoniques sont précieux)
- [ ] Extension de formulaire de lead (si utilisée)
- [ ] Extensions de prix (si applicable)
- [ ] Extensions d'image (où disponibles)

### Protection de marque

- [ ] Campagne de marque active (protéger les termes de marque)
- [ ] Campagnes concurrents envisagées
- [ ] Termes de marque dans les listes négatives pour les campagnes non-marque

## Configuration Meta Ads

### Fondations du Business Manager

- [ ] Business Manager créé
- [ ] Business vérifié (si vous lancez certains types d'annonces)
- [ ] Compte pub créé au sein du Business Manager
- [ ] Moyen de paiement ajouté
- [ ] Accès équipe configuré avec les bons rôles

### Pixel & tracking

- [ ] Meta Pixel installé sur toutes les pages
- [ ] Événements standard configurés :
  - PageView (automatique)
  - ViewContent (pages produit/fonctionnalité)
  - Lead (soumissions de formulaire)
  - Purchase (conversions)
  - AddToCart (si e-commerce)
  - InitiateCheckout (si e-commerce)
- [ ] Conversions API (CAPI) configurée pour le tracking côté serveur
- [ ] Event Match Quality score > 6
- [ ] Événements de test dans l'Events Manager

### Domaine & événements agrégés

- [ ] Domaine vérifié dans le Business Manager
- [ ] Aggregated Event Measurement configuré
- [ ] 8 principaux événements priorisés par ordre d'importance
- [ ] Événements web priorisés pour le tracking iOS 14+

### Configuration des audiences

- [ ] Custom audiences créées :
  - Visiteurs du site web (tous, 30/60/90/180 jours)
  - Visiteurs de pages clés
  - Vues vidéo (25 %, 50 %, 75 %, 95 %)
  - Personnes ayant interagi avec la page/Instagram
  - Liste clients uploadée
- [ ] Lookalike audiences créées (1 %, 1-3 %)
- [ ] Audiences sauvegardées pour le ciblage courant

### Catalogue (e-commerce)

- [ ] Catalogue produit connecté
- [ ] Flux produit se mettant à jour correctement
- [ ] Campagnes catalog sales activées
- [ ] Dynamic product ads configurées

### Assets créatifs

- [ ] Images aux bonnes tailles :
  - Feed : 1080x1080 (1:1)
  - Stories/Reels : 1080x1920 (9:16)
  - Paysage : 1200x628 (1.91:1)
- [ ] Vidéos aux bons formats
- [ ] Variations de copy pub prêtes
- [ ] Paramètres UTM dans toutes les URL de destination

### Conformité

- [ ] Special Ad Categories déclarées (si logement, crédit, emploi, politique)
- [ ] La landing page respecte les politiques de Meta
- [ ] Aucun contenu interdit dans les annonces

## Configuration LinkedIn Ads

### Fondations du Campaign Manager

- [ ] Compte Campaign Manager créé
- [ ] Page Entreprise connectée
- [ ] Informations de facturation ajoutées
- [ ] Accès équipe configuré

### Insight Tag & tracking

- [ ] LinkedIn Insight Tag installé sur toutes les pages
- [ ] Tag vérifié et se déclenchant
- [ ] Tracking de conversion configuré :
  - Conversions basées URL
  - Conversions par événement spécifique
- [ ] Valeurs de conversion définies (si applicable)

### Configuration des audiences

- [ ] Matched Audiences créées :
  - Audiences de retargeting du site web
  - Liste d'entreprises uploadée (pour l'ABM)
  - Liste de contacts uploadée
- [ ] Lookalike audiences créées
- [ ] Audiences sauvegardées pour le ciblage courant

### Lead Gen Forms (si utilisés)

- [ ] Templates de lead gen form créés
- [ ] Champs de formulaire sélectionnés (minimiser pour la conversion)
- [ ] URL de politique de confidentialité ajoutée
- [ ] Message de remerciement configuré
- [ ] Intégration CRM configurée (ou process d'export CSV)

### Document Ads (si utilisés)

- [ ] Documents uploadés (PDF, PowerPoint)
- [ ] Gating configuré (gate complet ou aperçu)
- [ ] Lead gen form connecté

### Assets créatifs

- [ ] Annonces image unique : 1200x627 (1.91:1) ou 1080x1080 (1:1)
- [ ] Images de carousel prêtes
- [ ] Specs vidéo respectées (si utilisée)
- [ ] Copy pub dans les limites de caractères :
  - Texte d'intro : 600 max, 150 recommandés
  - Titre : 200 max, 70 recommandés

### Considérations budgétaires

- [ ] Budget réaliste pour les CPC LinkedIn (8-15 €+ typiques)
- [ ] Taille d'audience validée (50K+ recommandé)
- [ ] Budget quotidien vs total décidé
- [ ] Stratégie d'enchères sélectionnée

## Configuration Twitter/X Ads

### Fondations du compte

- [ ] Compte Ads créé
- [ ] Moyen de paiement ajouté
- [ ] Compte vérifié (si requis)

### Tracking

- [ ] Twitter Pixel installé
- [ ] Événements de conversion créés
- [ ] Tag du site web vérifié

### Configuration des audiences

- [ ] Tailored audiences créées :
  - Visiteurs du site web
  - Listes clients
- [ ] Lookalikes de followers identifiés
- [ ] Cibles d'intérêt et de mots-clés recherchées

### Créa

- [ ] Copy du tweet dans les 280 caractères
- [ ] Images : 1200x675 (1.91:1) ou 1200x1200 (1:1)
- [ ] Specs vidéo respectées (si utilisée)
- [ ] Cards configurées (site web, app, etc.)

## Configuration TikTok Ads

### Fondations du compte

- [ ] Compte TikTok Ads Manager créé
- [ ] Vérification business complétée
- [ ] Moyen de paiement ajouté

### Pixel & tracking

- [ ] TikTok Pixel installé
- [ ] Événements configurés (ViewContent, Purchase, etc.)
- [ ] Events API configurée (recommandé)

### Configuration des audiences

- [ ] Custom audiences créées
- [ ] Lookalike audiences créées
- [ ] Catégories d'intérêt identifiées

### Créa

- [ ] Vidéo verticale (9:16) prête
- [ ] Contenu au rendu natif (pas trop léché)
- [ ] Les 3 premières secondes sont des hooks accrocheurs
- [ ] Sous-titres ajoutés (la plupart regardent sans le son)
- [ ] Musique/sons sélectionnés (sous licence si nécessaire)

## Checklist universelle pré-lancement

Avant de lancer n'importe quelle campagne :

- [ ] Tracking de conversion testé avec une vraie conversion
- [ ] La landing page charge vite (<3 sec)
- [ ] Landing page mobile-friendly
- [ ] Paramètres UTM fonctionnels
- [ ] Budget réglé correctement (quotidien vs total)
- [ ] Dates de début/fin correctes
- [ ] Le ciblage correspond à l'audience visée
- [ ] Créa pub approuvée
- [ ] Équipe informée du lancement
- [ ] Dashboard de reporting prêt
