# Référence des limites des plateformes

Référence rapide pour les limites de hashtags, décomptes de caractères et seuils de texte visible sur chaque grande plateforme sociale.

---

## Instagram

| Élément | Limite |
|---------|-------|
| Hashtags max | 5 (limite officielle) |
| Hashtags recommandés | 3 – 5 |
| Caractères max de légende | 2 200 |
| Visible avant « plus » | ~125 car. |

---

## Facebook

| Élément | Limite |
|---------|-------|
| Hashtags max | Pas de limite officielle |
| Hashtags recommandés | 1 – 2 |
| Caractères max de post | 63 206 |
| Idéal pour l'engagement | 40 – 80 car. |

---

## TikTok

| Élément | Limite |
|---------|-------|
| Hashtags max | 5 (depuis août 2025) |
| Hashtags recommandés | 3 – 5 |
| Caractères max de légende | 4 000 |
| Visible avant « plus » | ~150 car. |

---

## LinkedIn

| Élément | Limite |
|---------|-------|
| Hashtags max | Pas de limite officielle |
| Hashtags recommandés | 3 – 5 |
| Caractères max de post | 3 000 |
| Visible avant « plus » | ~210 car. |

---

## Twitter/X

| Élément | Limite |
|---------|-------|
| Hashtags max | Pas de limite officielle |
| Hashtags recommandés | 1 – 2 |
| Caractères max de tweet | 280 (standard) / 25 000 (Premium+) |
| Visible avant « plus » | Tweet complet (280 standard) |

---

## YouTube

| Élément | Limite |
|---------|-------|
| Hashtags max | 15 (au-delà, YouTube ignore TOUS les hashtags) |
| Hashtags recommandés | 3 – 5 |
| Caractères max de titre | 100 (visible avant troncature : ~70) |
| Caractères max de description | 5 000 |
| Visible avant « Afficher plus » | ~100 car. |

> Les 3 premiers hashtags de la description apparaissent automatiquement au-dessus du titre sous forme de liens cliquables. Pour les Shorts, utiliser 1 – 5 hashtags.

---

## Pinterest

| Élément | Limite |
|---------|-------|
| Hashtags max | 20 par épingle |
| Hashtags recommandés | 2 – 5 |
| Caractères max de titre d'épingle | 100 |
| Caractères max de description | 500 |
| Visible avant « Plus » | ~50 car. (desktop) |

> Pinterest a déprioritisé les hashtags. Privilégier les mots-clés sous forme de phrases naturelles dans la description pour un meilleur SEO plutôt que de s'appuyer sur les hashtags.

---

## Threads (Meta)

| Élément | Limite |
|---------|-------|
| Hashtags max | 1 par post (topic tag) |
| Hashtags recommandés | 1 |
| Caractères max de post | 500 |
| Max avec pièce jointe texte | 10 500 (500 + 10 000 extensibles) |
| Visible sans déplier | Les ~1 – 2 premières lignes |

> Threads limite les topic tags à un par post. La plateforme n'est pas pilotée par les hashtags — l'algorithme priorise le contenu des comptes suivis mélangé à des recommandations.

---

## Astuces d'usage

- **Les hashtags comptent dans les limites de caractères** sur toutes les plateformes
- **Mettre votre message en premier** avant le point de troncature « plus »
- Sur Instagram et TikTok, moins de hashtags surperforment désormais le bourrage de hashtags
- Sur LinkedIn, les hashtags en fin de post performent mieux qu'en ligne
- Sur Facebook, les hashtags ont un impact minime sur la portée — à utiliser avec parcimonie
