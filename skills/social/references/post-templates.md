# Templates de format de post

Templates prêts à l'emploi pour différentes plateformes et types de contenu.

## Sommaire
- Templates de post LinkedIn (Le post histoire, La prise à contre-courant, Le post liste, Le tuto)
- Templates de thread Twitter/X (Le thread tutoriel, Le thread histoire, Le thread décryptage)
- Templates Instagram (Le hook de carousel, Le script de Reel)
- Formules de hook (Hooks de curiosité, Hooks d'histoire, Hooks de valeur, Hooks à contre-courant, Hooks de preuve sociale)

## Templates de post LinkedIn

### Le post histoire
```
[Hook : Résultat ou leçon inattendue]

[Planter le décor : Quand/où c'est arrivé]

[Le défi auquel vous avez fait face]

[Ce que vous avez essayé / ce qui s'est passé]

[Le tournant]

[Le résultat]

[La leçon pour les lecteurs]

[Question pour amorcer l'engagement]
```

### La prise à contre-courant
```
[Opinion impopulaire énoncée avec aplomb]

Voici pourquoi :

[Raison 1]
[Raison 2]
[Raison 3]

[Ce que vous recommandez à la place]

[Inviter la discussion : « J'ai tort ? »]
```

### Le post liste
```
[X choses que j'ai apprises sur [sujet] après [élément de crédibilité] :

1. [Point] — [Brève explication]

2. [Point] — [Brève explication]

3. [Point] — [Brève explication]

[Insight de conclusion]

Lequel résonne le plus chez vous ?
```

### Le tuto
```
Comment [atteindre un résultat] en [délai] :

Étape 1 : [Action]
↳ [Pourquoi c'est important]

Étape 2 : [Action]
↳ [Détail clé]

Étape 3 : [Action]
↳ [Erreur courante à éviter]

[Résultat auquel vous pouvez vous attendre]

[CTA ou question]
```

## Templates de thread Twitter/X

### Le thread tutoriel
```
Tweet 1 : [Hook + promesse de valeur]

« Voici exactement comment [résultat] (étape par étape) : »

Tweet 2-7 : [Une étape par tweet avec détails]

Dernier tweet : [Résumé + CTA]

« Si ça vous a aidé, suivez-moi pour plus sur [sujet] »
```

### Le thread histoire
```
Tweet 1 : [Hook intrigant]

« Il y a [temps], [chose inattendue est arrivée]. Voici toute l'histoire : »

Tweet 2-6 : [Temps forts de l'histoire, montée de la tension]

Tweet 7 : [Résolution et leçon]

Dernier tweet : [Point à retenir + appel à l'engagement]
```

### Le thread décryptage
```
Tweet 1 : [Entreprise/personne] vient de [faire une chose].

Voici pourquoi c'est génial (et ce que vous pouvez en apprendre) :

Tweet 2-6 : [Points d'analyse]

Tweet 7 : [Votre point à retenir clé]

« [Insight lié + CTA de suivi] »
```

## Templates Instagram

### Le hook de carousel
```
[Slide 1 : Affirmation ou question audacieuse]
[Slides 2-9 : Un point par slide, visuel + texte]
[Slide 10 : Résumé + CTA]

Légende : [Développer le sujet, ajouter du contexte, inclure un CTA]
```

### Le script de Reel
```
Hook (0-2 sec) : [Pattern interrupt ou affirmation audacieuse]
Mise en place (2-5 sec) : [Contexte de l'astuce]
Valeur (5-25 sec) : [Le conseil/contenu réel]
CTA (25-30 sec) : [Suivre, commenter, partager, lien]
```

## Formules de hook

La première ligne détermine si quiconque lit la suite.

### Hooks de curiosité
- « Je me suis trompé sur [croyance courante]. »
- « La vraie raison pour laquelle [résultat] arrive n'est pas ce que vous pensez. »
- « [Résultat impressionnant] — et ça n'a pris que [temps étonnamment court]. »
- « Personne ne parle de [connaissance d'initié]. »

### Hooks d'histoire
- « La semaine dernière, [chose inattendue] est arrivée. »
- « J'ai failli [grosse erreur/échec]. »
- « Il y a 3 ans, j'étais [état passé]. Aujourd'hui, [état actuel]. »
- « [Personne] m'a dit une chose que je n'oublierai jamais. »

### Hooks de valeur
- « Comment [résultat désiré] (sans [douleur courante]) : »
- « [Nombre] [choses] qui [résultat] : »
- « La façon la plus simple de [résultat] : »
- « Arrêtez [erreur courante]. Faites ça à la place : »

### Hooks à contre-courant
- « Opinion impopulaire : [affirmation audacieuse] »
- « [Conseil courant] est faux. Voici pourquoi : »
- « J'ai arrêté [pratique courante] et [résultat positif]. »
- « Tout le monde dit [X]. La vérité, c'est [Y]. »

### Hooks de preuve sociale
- « Nous avons [atteint un résultat] en [délai]. Voici toute l'histoire : »
- « [Nombre] personnes m'ont posé des questions sur [sujet]. Voici ma réponse : »
- « [Figure d'autorité] m'a appris [leçon]. »
